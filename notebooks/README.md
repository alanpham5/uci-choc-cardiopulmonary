# Setup Instructions

Please follow the steps below before running or reviewing the notebooks.

## Step 1: Upload Notebooks to Google Drive

1. Open **Google Drive** in your browser.
2. Create a new folder for this project if one does not already exist.
3. Upload all provided Jupyter notebook files (`.ipynb`) into this folder.
4. Open the notebooks using **Google Colab** by right clicking each file and selecting  
   **Open with → Google Colaboratory**.

## Step 2: Upload Simulation Data

1. Open the main notebook in Google Colab.
2. At the beginning of the notebook, locate and run the **file upload cell**.
3. When prompted, upload the simulation data files located in: data/Simulated Data/ from your Google Drive.
4. Verify that the files appear in the Colab file system before continuing.
5. After the data upload is complete, run the remaining cells in order.

## Notes

- The file upload cell must be run before any other cells.
- Do not proceed until all simulation data files have been successfully uploaded.
- Running cells out of order may result in errors or missing data.
